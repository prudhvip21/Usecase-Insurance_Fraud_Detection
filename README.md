# Insurance Fraud Detection

Identify fraudulent insurance claims and the factors associated with them.

## Approach

- Exploratory analysis of the `fraud_reported` target
- Feature selection and preprocessing
- Comparison of Logistic Regression, Decision Tree, Random Forest, AdaBoost, Gradient Boosting, KNN, Naive Bayes and SVM

## Results

Accuracy between about 0.74 and 0.81 in the saved notebook output.
